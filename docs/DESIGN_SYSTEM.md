# QueueBite Design System

## Brand Personality

- Friendly
- Elegant
- Warm
- Fast
- Modern

## User Emotion

- Welcomed
- Relaxed
- Confident
- Hungry

## Design Principles

- Simplicity over decoration
- Whitespace is intentional
- Warm colors with balanced contrast
- Consistent spacing and typography
- Accessible and responsive UI

## Color Roles

- Primary → Warm Orange
- Secondary → Golden Yellow
- Accent → Fresh Green
- Background → Soft Cream
- Surface → White
- Text → Charcoal
